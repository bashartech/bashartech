## 👥 2. Resume Screener AI — Intelligent Recruitment Platform

🔗 **Live Demo:** [automations-r3k4.vercel.app](https://automations-r3k4.vercel.app/)

An AI-powered recruitment platform that automates bulk resume screening, candidate ranking, and hiring workflow management.

### 🔥 Key Features

- Process resumes in bulk from PDF, DOCX, PNG, JPG, BMP, TIFF, and TXT files.
- Extract text from scanned resumes using Tesseract OCR.
- Generate structured candidate profiles using LLMs.
- Score and rank candidates against job descriptions on a 0–100 scale.
- Detect duplicate candidates using exact-field matching and embedding similarity.
- Manage companies, departments, jobs, interviews, notes, tags, and candidate statuses.
- Export candidate data to CSV and compare applicants.
- Support credit-based billing and Stripe checkout.
- Schedule interviews with calendar invitations and Google Calendar integration.

### ☁️ Architecture

- Frontend: Next.js
- Backend: FastAPI
- Background Processing: Celery and Celery Beat
- Infrastructure: AWS ECS Fargate
- Database: Neon PostgreSQL
- Message Broker: Upstash Redis

### ⚙️ Technology Focus

`Next.js` `FastAPI` `Python` `Celery` `AWS ECS` `PostgreSQL` `Redis` `LLMs` `OCR` `Stripe`
